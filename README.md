# QMT 日线策略：MA20 + MACD 双信号动量策略

基于迅投 QMT（大 QMT）〖模型研究〗内置 Python 环境的日线量化策略。回测结束后**自动**将成交明细、每日净值序列、Markdown 绩效报告导出到本地目录，无需在 QMT 界面手动查看或导出。

- 策略代码：[strategy/ma_macd_dual_signal.py](strategy/ma_macd_dual_signal.py)
- 原始需求：[doc/initial_prompt.txt](doc/initial_prompt.txt)

## 策略逻辑

| 维度 | 规则 |
|---|---|
| 标的 | 沪深300 成分股 |
| 买入信号 | 收盘价**上穿** 20 日均线，且 MACD 柱状线（hist）> 0 |
| 卖出信号 | 收盘价**下穿** 20 日均线，或 持仓盈利回撤 > 5% |
| 仓位 | 每只股票等权分配（总资产 / 最多持仓数），最多同时持有 5 只 |
| 调仓频率 | 每日 K 线触发一次（`handlebar`），收盘前检查信号 |

> 买入时按 MACD 柱状线降序选动量更强的标的；卖出按 A 股 T+1 规则（用券商返回的 `m_nCanUseVolume` 确定可卖数量）。

## 技术约束实现

1. **QMT 标准回调结构**：`init` / `handlebar` / `stop` 三段式，使用 `ContextInfo` 上下文。
2. **数据获取**：`ContextInfo.get_history_data()` 取历史收盘价；`get_trade_detail_data(account, 'STOCK', 'ACCOUNT'/'POSITION'/'DEAL')` 取账户、持仓、成交。
3. **下单**：`passorder()`（限价单，按当前收盘价）。
4. **自动报告**：`stop()` 中收集 → 计算 → 导出，**异常全部被 `try/except` 捕获**，导出失败也不会影响策略运行。

## 导出文件

回测结束后自动写入 `G:/QMT_Reports/`（目录不存在则自动创建）：

| 文件 | 内容 | 编码 |
|---|---|---|
| `backtest_trades.csv` | 每笔成交明细（代码 / 方向 / 时间 / 价格 / 数量） | UTF-8（带 BOM，Excel 友好） |
| `backtest_nav.csv` | 每日净值序列（日期 / 总资产 / 日收益率） | UTF-8 |
| `backtest_report.md` | Markdown 绩效汇总报告 | UTF-8 |

`backtest_report.md` 包含：策略名与回测时间段、核心绩效指标表（年化收益、最大回撤、夏普比率、胜率、交易次数等）、收益曲线文字描述、前 10 笔成交明细表。

## 使用步骤

### 第 1 步：下载日线历史数据（回测前必做）

在 QMT 客户端打开 **〖数据管理〗 → 〖行情数据下载〗**：

- 品种：勾选 **沪深300** 板块（一次下载全部成分股）；
- 周期：**日线**；
- 时间区间：覆盖回测起止日期，**并往前多下载 2 个月**（供 20 日均线与 MACD 暖机使用）。

> 若未下载日线数据，`handlebar` 中 `get_history_data` 返回为空，策略不会有任何交易——这是“回测无成交”最常见的原因。

### 第 2 步：粘贴策略并配置回测参数

1. 打开 **〖模型研究〗 → 新建策略**，把 [strategy/ma_macd_dual_signal.py](strategy/ma_macd_dual_signal.py) 的全部内容粘贴进去，保存。
2. （可选）在代码顶部把 `ACCOUNT_ID` 改成你的资金账号；或在回测参数里选账号。
3. 点“回测”，按以下参数设置：

| 参数 | 建议值 | 说明 |
|---|---|---|
| 周期 | 日线 | — |
| 开始时间 | 如 `2020-01-01` | 与下载数据区间匹配 |
| 结束时间 | 如 `2024-12-31` | — |
| 初始资金 | 如 `1,000,000` | 等权仓位据此分配 |
| 佣金（买卖） | `0.0003` | 万三 |
| 印花税 | `0.001` | 仅卖出单边 |
| 过户费 | `0.00002` | 沪市单边，深市免 |
| 滑点 | `0.001` | 千一，可按需调 `0` |

4. 点“开始回测”。结束后查看 `G:/QMT_Reports/` 下的三个文件。

## 绩效指标口径

- **年化收益率**：`(期末/期初)^(252/交易日数) - 1`（几何年化）。
- **最大回撤**：净值序列相对历史峰值的最大跌幅。
- **夏普比率**：日收益率均值 / 标准差 × √252（无风险利率取 0）。
- **胜率**：按股票代码分组、时间排序，FIFO 匹配买入→卖出，盈利平仓笔数占总平仓笔数比例。

## 常见排错

| 现象 | 处理 |
|---|---|
| 回测无成交 | 先确认已下载日线数据；再核对 `passorder` 的 `ORDER_TYPE_LIMIT`，部分 QMT 版本为 `0`，可把代码顶部常量改成 `0` 再试 |
| CSV 中文乱码 | 文件已用 `utf-8-sig`（带 BOM）；如仍乱码，用 Excel“数据 → 从文本”导入并选 UTF-8 |
| `to_markdown` 报错 | 未装 `tabulate`，代码已自动回退为手写 Markdown 表格，无需处理 |
| 中文注释乱码 | 策略文件为 **GBK** 编码（QMT 模型研究要求，首行已声明 `# -*- coding: gbk -*-`）。本项目 `.vscode/settings.json` 已为 Python 文件配置 GBK，VSCode 会自动正确显示；用其他编辑器打开时请手动选 GBK 编码 |

> 说明：QMT 不同版本间 `get_history_data` / `passorder` 的参数取值偶有差异。代码已在数据取数处做签名兼容与异常兜底，并在 `passorder` 常量处集中标注；如某项不生效，按“常见排错”调整对应常量即可。
